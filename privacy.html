Privacy policy

Last updated October 10, 2026.

Botville is a personal app that one person (the owner) runs on their own computer. Its only user is the owner, and the only Google account it connects to is the owner's own. This page explains what it does with that account's data.

What Botville accesses

  • Gmail, read-only (gmail.readonly): new messages in the inbox, so it can sort them and write digests.
  • Gmail drafts (gmail.compose), only if the owner turns it on: to save a reply as a draft after the owner approves it. Botville never sends email.

What it stores, and for how long

  • For each email: sender, subject, date, a link back to Gmail, and Botville's sorting (topic, importance, any deadline, a one-line summary). Kept for 14 days, then deleted.
  • Message IDs it has already seen, kept for 3 days so the same email isn't handled twice.
  • Email bodies are not stored.
  • Everything is stored on the owner's own computer. Nothing is stored on a server run by anyone else.
  • The Google sign-in token is stored on the owner's computer and is never shown or shared.

Who else sees it

  • Anthropic (Claude): to sort an email, summarise it, and (if the owner allows) draft a reply, Botville sends its sender, subject, date and up to 2,000 characters of its text to Anthropic's Claude API. Digest summaries are sent the same way to write the owner's daily briefing. This happens only to provide these features to the owner.
  • The owner's own Discord server: urgent-email alerts and digest headlines are posted to a private Discord server that belongs to the owner.
  • No one else. Botville does not sell, rent or share Google user data, does not use it for advertising, and does not use it to train AI models.

Google API Services User Data Policy

Botville's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can disconnect Gmail at any time in Botville (Setup → Gmail → Disconnect), which also cancels the sign-in with Google. Access can also be removed from Google's side at myaccount.google.com/permissions.
